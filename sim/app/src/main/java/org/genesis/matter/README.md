# matter — la molécule et la matière

| Classe | Rôle |
|---|---|
| `MoleculeCanvas` | L'échelle de la molécule : deux atomes, et ce que font leurs électrons (densité, énergie, orbitales). |
| `MatterCanvas` | L'échelle de la matière : des centaines d'atomes dans une boîte, un piston, des mesures. |

Le moteur correspondant : `logic/molecular/`.
