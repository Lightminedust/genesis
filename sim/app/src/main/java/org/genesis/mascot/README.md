# mascot — Genesis, la guide

**Mise de côté.** Le code est gardé, mais Genesis n'est pas affichée. Pour la retrouver : passer `GENESIS_ENABLED` à `true` dans `app/App.java` (la bascule « Journal / Genesis » réapparaît dans le journal).

| Classe | Rôle |
|---|---|
| `GenesisMascot` | La boule de verre, le socle, les humeurs, la bulle de texte, les explications en mots simples de chaque événement. |
| `GenesisBlob` | Son corps : une boule de matière noire à deux oreilles, peinte pixel par pixel. |
| `GenesisFlask` | Sa division en masses qui flottent (metaballs) et les résidus de matière (particules). |

Tests et aperçu (`gradlew mascotPreview`) : `sim/app/src/test/java/org/genesis/mascot/`.
