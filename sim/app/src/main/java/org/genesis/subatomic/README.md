# subatomic — le monde subatomique

| Classe | Rôle |
|---|---|
| `QuantumLab` | L'écran : trois ateliers sous un même style documentaire. |
| `CollisionScene` | La collision électron + nucléon, en 3D, racontée en étapes. |
| `HadronBench` | L'atelier de hadrons : choisir un moule, poser des quarks. |
| `SmTable` | Le tableau du Modèle Standard. |
| `PartonView` | La mer de partons : le nucléon à une résolution donnée. |
| `SubRender` | Le rendu 3D de ces écrans : nébuleuse, quarks en sphères lumineuses. |
| `DocStyle` | Le style « documentaire » : couleurs, polices, fonds. |
| `SubatomicView` | Le premier laboratoire subatomique : quelques nucléons intégrés par le moteur. |

Le moteur correspondant : `logic/quantumlab/`. Les modèles : `docs/SUBATOMIC_MODEL.md`, `docs/NUCLEON_MODEL.md`. Tests et aperçus : `sim/app/src/test/java/org/genesis/subatomic/`.
